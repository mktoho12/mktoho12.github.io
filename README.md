# mktoho.dev

個人サイト。AIと一緒にやっていることの記録と自己紹介。

**https://mktoho.dev/**

## 構成

素の HTML/CSS 1枚。ビルドなし、依存なし（Webフォントのみ）。
GitHub Pages で公開。

```
index.html          サイト本体
assets/icon.png     アイコン
```

## 更新のしかた

`index.html` を直接編集して push するだけ。
プロジェクトを増やすときは「つくったもの」セクションの `.grid` に
`<a class="proj">` を1つ足す。

## アイコンについて

Skeb で依頼して描いてもらったもの。著作権は絵師にあります。
